# Deepak R — Portfolio

A lightweight, responsive static portfolio for Deepak R. Content is limited to verified information available in the source repository: ISEP Batch 1 participation and the Smart India Hackathon agricultural crop anomaly detection and advisory project, including its finalist result.

## Run locally

Open `index.html` directly, or serve this folder with:

```powershell
python -m http.server 4173
```
